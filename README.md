# AI Power BI Dashboard Generator

## Project
**Cross-Channel Digital Marketing Campaign Performance Analysis Using Business Intelligence and AI Agent**

This project builds an AI-driven BI orchestration system that accepts a marketing campaign CSV, analyzes and validates the data, selects dashboard components, produces a structured dashboard specification, and is designed to generate/configure and publish a Power BI report. An AI analytics layer provides data-backed insights, anomaly detection, natural-language questions, recommendations, and automated reporting.

## Source scope
The project abstract specifies approximately 200,000 records and 10 fields:
- Campaign_ID
- Company
- Campaign_Type
- Target_Audience
- Duration
- Channel_Used
- Conversion_Rate
- Acquisition_Cost
- ROI
- Location

Required BI areas include channel performance, audience segmentation, campaign type comparison, duration impact, geographic performance, cost efficiency, company benchmarking, top/bottom performers, and interactive filters.

## Implementation strategy
1. Local data intelligence engine.
2. Dashboard plan generation.
3. Power BI-ready report definition.
4. Power BI Desktop validation.
5. Power BI Service/Fabric publishing.
6. AI analytics chat and automated reporting.

Do not make Power BI Service authentication a prerequisite for local development.
