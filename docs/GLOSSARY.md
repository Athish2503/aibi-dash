# Glossary

**Agent:** Software component that selects and coordinates tools.

**Dashboard Plan:** Typed specification of KPIs, pages, visuals, fields, and filters.

**Deterministic Tool:** Function whose result follows explicit input and rules.

**KPI:** Key Performance Indicator.

**PBIR / Report Definition:** Structured representation used for Power BI report content; exact supported workflow must be verified during implementation.

**Semantic Model:** Analytical model containing tables, fields, measures, relationships, and metadata.

**Insight:** Natural-language observation grounded in computed data.

**Anomaly:** Observation identified as unusual using a defined method.

**Recommendation:** Historical-data-based suggestion, not a guarantee.
