# Implementation Plan

## Phase 0 — Foundation
Repository, Python environment, requirements, environment template, test setup.
Exit: health endpoint works.

## Phase 1 — Dataset intelligence
Inspector, validator, profiler, cleaner.
Exit: target CSV/XLSX is correctly inspected/validated.

## Phase 2 — Analytics
KPIs, channels, audiences, campaign types, duration, geography, company, rankings, cost efficiency, anomalies.
Exit: deterministic outputs with tests.

## Phase 3 — Dashboard planner
Typed plan schemas, visualization selector, planner, validator.
Exit: validated dashboard-plan JSON.

## Phase 4 — Agent
Tool registry, orchestrator, LLM adapter, NL query, insights, recommendations.
Exit: agent calls tools and grounds answers.

## Phase 5 — Power BI-ready generation
Semantic model, measures, report-definition builder, template strategy, structural validation.
Exit: report artifacts validate.

## Phase 6 — Desktop validation
Verify generated report artifacts in the available local Power BI environment.

## Phase 7 — Power BI Service
Authentication, workspace adapter, publishing, refresh, status, report link.
Exit: configured cloud end-to-end flow.

## Phase 8 — React
Upload, progress, plan review, result, chat.

## Phase 9 — Testing
Unit, integration, contract, end-to-end, failure-path.

## Phase 10 — Demonstration
Upload → analysis → AI plan → dashboard → NL question → evidence → anomaly/recommendation.
