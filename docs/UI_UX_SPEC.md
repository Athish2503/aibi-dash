# UI/UX Specification

## Screens
### Home
Project explanation, CSV upload, recent jobs.

### Dataset Analysis
Filename, row/column counts, validation status, missing values, duplicates, detected types.

### Generation
Stepper:
Upload → Inspect → Validate → Analyze → Plan → Generate → Publish

### Dashboard Plan
Show selected KPIs, pages, visuals, filters, and rationale. Allow review before generation.

### Result
Show status, Power BI link when available, generated artifacts, and summary.

### AI Analytics
Chat with answer, evidence, filters used, and tools used.

## UX principles
- Clear business-dashboard style.
- Desktop-first.
- Explicit loading/error states.
- Accessible labels.
- Do not present unsupported AI claims as facts.
- Make evidence visible.
